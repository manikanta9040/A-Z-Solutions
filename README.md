# A-Z Solutions

This project is a React + Vite website scaffold for A-Z Solutions, with page routing and reusable components.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal to preview the site.

## Build

```bash
npm run build
```

## Project structure

- `src/App.tsx` — application shell and layout
- `src/main.tsx` — React entry point
- `src/routes/AppRoutes.tsx` — route definitions
- `src/pages/` — page views
- `src/components/` — reusable UI components and sections
- `src/services/` — data fetching logic
- `src/hooks/` — custom React hooks
- `src/types/` — shared TypeScript types
- `src/utils/` — helper utilities
- `public/data/conferences.json` — sample conference data
